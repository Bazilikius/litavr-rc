# Raspberry Pi Pico (та Pico W) Контролер CRSF у PWM на MicroPython

Ця директорія містить повноцінний порт коду приймача CRSF (TBS Crossfire / ELRS) для **Raspberry Pi Pico** та **Raspberry Pi Pico W**, написаний на **MicroPython**.

Проект приймає вхідний потік кадрів протоколу CRSF через апаратний інтерфейс UART, декодує канали керування RC та керує трьома незалежними ШІМ (PWM) виходами: **Перемикач (Switch)**, **Сервопривід (Servo)** та **Перемикач камери (Camera Switch)**. Крім того, на платі Pico W підтримується локальна бездротова точка доступу WiFi з веб-інтерфейсом налаштування та моніторингу в реальному часі.

---

## Схема підключення (RPi Pico)

| Компонент | Вивід Pico | Опис | Примітка |
| --- | --- | --- | --- |
| **CRSF RX** | GP1 | UART0 RX | Слухає сигнал TX від приймача ELRS/Crossfire |
| **CRSF TX** | GP0 | UART0 TX | Не використовується (лише пасивне читання) |
| **Перемикач PWM** | GP5 | Вихід ШІМ | Керується налаштованим каналом та лімітами |
| **Сервопривід PWM** | GP4 | Вихід ШІМ | Керується налаштованим каналом та лімітами |
| **Камера PWM** | GP3 | Вихід ШІМ | Керується налаштованим каналом та лімітами |
| **GND** | GND | Спільна земля | Обов'язкове з'єднання земель плати, приймача та серво |
| **VCC / 5V** | VSYS / VBUS | Живлення | Живлення плати Pico та приймача |

## Структура файлів проекту

- `main.py` — головний цикл програми, який зчитує байти з UART, викликає парсер, оновлює виходи PWM та обслуговує запити веб-сервера.
- `crsf_parser.py` — надійний парсер протоколу CRSF із логікою ковзного вікна для відновлення синхронізації, перевіркою CRC8 та розпакуванням 11-бітних каналів.
- `pwm_controller.py` — високоточний контролер ШІМ на базі `machine.PWM` (використовує наносекунди `duty_ns` для точного позиціонування) та виконує калібрувальний "свіп" при запуску.
- `config_manager.py` — менеджер збереження налаштувань у форматі JSON (енергонезалежна пам'ять Pico Flash).
- `web_server.py` — модуль WiFi Access Point та легковагого веб-сервера (для Pico W), що віддає AJAX-панель моніторингу та зберігає параметри конфігурації.

## Налаштування та запуск на платі Raspberry Pi Pico / Pico W

1. **Встановлення MicroPython**:
   Завантажте актуальну версію MicroPython UF2 для вашої плати (Pico або Pico W) з офіційного сайту [micropython.org](https://micropython.org/download/) та прошийте плату.

2. **Завантаження коду**:
   Використовуючи середовище розробки **Thonny IDE** або утиліту `mpremote`/`ampy`, завантажте всі 5 файлів із цієї папки (`main.py`, `config_manager.py`, `crsf_parser.py`, `pwm_controller.py`, `web_server.py`) у кореневу директорію флеш-пам'яті Raspberry Pi Pico.

3. **Підключення апаратної частини**:
   З'єднайте вихід TX вашого приймача RC із піном GP1 (RX) плати Pico. Переконайтеся, що сервоприводи та перемикачі підключені до відповідних пінів (GP5, GP4, GP3) і мають спільну землю (GND).

4. **Тестування при запуску**:
   При кожному подаванні живлення пристрій здійснює діагностичний "рух" (Sweep) тривалістю 1.5 секунди для всіх трьох каналів (послідовно 1000мкс -> 1500мкс -> 2000мкс -> 1500мкс), щоб ви могли переконатися в справності сервоприводів та підключень.

## Конфігурація через WiFi (лише для Raspberry Pi Pico W)

1. Після запуску Pico W створить відкриту мережу WiFi:
   - **SSID**: `CRSF-Config`
   - **Пароль**: `12345678`
2. Підключіться до цієї мережі з телефону чи комп'ютера.
3. Відкрийте браузер та перейдіть за адресою: **`http://192.168.4.1`**
4. У вікні веб-інтерфейсу ви зможете:
   - Бачити реальний статус з'єднання, кількість зчитаних байтів та декодованих пакетів.
   - Моніторити вхідні значення всіх 16 CRSF каналів у реальному часі.
   - Перепризначати виходи (Перемикач, Серво, Камера) на будь-який вхідний канал CH1-CH16.
   - Задавати індивідуальні ліміти довжини імпульсу PWM (Min / Max у мікросекундах, від 500us до 2500us).
   - Обирати швидкість UART приймача (115200, 400000 або 420000 бод).
5. Натисніть **"Save & Apply Configuration"**. Налаштування збережуться у вбудовану пам'ять, а плата перезавантажиться для безпечного застосування конфігурації.
