# ESP32 CRSF LoRa Multi-Board Remote Control System

Цей проект розділено на дві повністю **незалежні прошивки** для плат ESP32:
1. **crsf_lora_tx (Передавач / Transmitter)**: Слухає CRSF потік на Serial2 і транслює канали через радіомодуль LoRa (Ebyte E32-433T30D або SX1278).
2. **crsf_lora_rx (Приймач / Receiver)**: Приймає радіосигнал LoRa і керує виконавчими механізмами (серви, ключі, світлодіоди).

---

## 1. Архітектура системи та радіомодулі

```
                    +------------------------------------+
                    |        CRSF Transmitter            |
                    | (Ebyte E32-433T30D / SX1278 LoRa)  |
                    +-----------------+------------------+
                                      |
                            [LoRa 433 MHz / 3km+ Range]
                                      |
        +---------------------+-------+-------+---------------------+
        |                     |               |                     |
        v                     v               v                     v
  +-------------+       +-------------+ +-------------+       +-------------+
  |  RX Node 1  |       |  RX Node 2  | |  RX Node 3  |       |  RX Node 4  |
  | (RFM95/98W) |       | (RFM95/98W) | | (RFM95/98W) |       | (RFM95/98W) |
  +-------------+       +-------------+ +-------------+       +-------------+
```

### Радіомодулі для дальності 3км+:
* **Передавач (TX)**: **Ebyte E32-433T30D** (потужність 1 Вт / 30dBm, частота 433MHz).
  * Контакти **M0 (GND)** та **M1 (GND)** з'єднані з землею для роботи у **Режимі прозорої передачі (Normal Mode)**.
* **Приймачі (RX)**: **RFM95 / RFM98W / SX1278** SPI LoRa чіпи.
  * Налаштування чутливості оптимізовано для роботи на відстані **3км+** (Spreading Factor: **SF11**, Bandwidth: **125 kHz**, Coding Rate: **4/5**, Low Data Rate Optimization увімкнено).

## 2. Схема підключення (ESP32 Dev Module)

### Плата передавача (Transmitter TX)
| Компонент / Пін | Пін ESP32 | Примітка |
| --- | --- | --- |
| **CRSF RX** | GPIO 16 (RX2) | Вхід сигналу від пульта / приймача TBS / ELRS |
| **E32 TXD** | GPIO 27 | Serial1 RX (прийом даних від E32) |
| **E32 RXD** | GPIO 17 | Serial1 TX (передача даних на E32) |
| **E32 M0** | GND | Режим прозорої передачі |
| **E32 M1** | GND | Режим прозорої передачі |
| **LoRa SS/CS** | GPIO 5 | SPI Slave Select |
| **LoRa SCK** | GPIO 18 | SPI SCK |
| **LoRa MISO** | GPIO 19 | SPI MISO |
| **LoRa MOSI** | GPIO 23 | SPI MOSI |

### Плата приймача (Receiver RX)
| Компонент / Пін | Пін ESP32 | Тип | Примітка |
| --- | --- | --- | --- |
| **Left Servo PWM** | GPIO 4 | Вихід | Лівий сервопривід (50Hz PWM) |
| **Right Servo PWM** | GPIO 13 | Вихід | Правий сервопривід (Синхронно, підтримує інверсію) |
| **Extra Output Pin** | GPIO 26 | Вихід | PWM вихід для RC-перемикача (АКТИВНИЙ = 2000us, НЕАКТИВНИЙ = 1000us) |

## 3. Інструкція з прошивки модулів LoRa (Arduino IDE)

Код повністю розділений на дві незалежні прошивки. Вам **не потрібно** копіювати файли між папками. Просто виконайте кроки для кожної плати:

### Крок 1. Прошивка Передавача (TX)
1. Відкрийте файл **`crsf_lora_tx/crsf_lora_tx.ino`** в Arduino IDE.
2. Підключіть плату передавача ESP32 до комп'ютера через USB.
3. У меню `Tools -> Board` оберіть **`ESP32 Dev Module`**.
4. Оберіть відповідний COM-порт.
5. Натисніть кнопку **Upload** (стрілочка вправо).

### Крок 2. Прошивка Приймача (RX)
1. Відкрийте файл **`crsf_lora_rx/crsf_lora_rx.ino`** в Arduino IDE.
2. Підключіть плату приймача ESP32 до комп'ютера через USB.
3. У меню `Tools -> Board` оберіть **`ESP32 Dev Module`**.
4. Оберіть відповідний COM-порт.
5. Натисніть кнопку **Upload**.

## 4. Алгоритм роботи та унікальні функції

1. **Синхронізований рух двох сервоприводів**:
   - Керує двома сервоприводами (Left на GPIO 4, Right на GPIO 13).
   - У веб-інтерфейсі можна незалежно інвертувати рух лівої або правої серво для механічного узгодження.
   - Швидкість руху обмежена до дуже плавної: **250us за 60 секунд** (плавний рух діє відразу після ввімкнення приймача).
   - На старті (в setup) плата зчитує верхній кінцевик для уникнення різких рухів чи ривків: якщо кінцевик спрацював, старт з 2200us, інакше з 1500us.

2. **Керування Кінцевиком Servo UP (GPIO 25)**:
   - Пін GPIO 25 налаштований як кінцевик Servo UP.
   - Коли кінцевик **відкритий (HIGH)** — сервоприводи автоматично піднімаються у крайнє положення (**2200us**).
   - Коли кінцевик **натиснутий (LOW)** — сервоприводи опускаються у початкове положення (**1500us**) або працюють у штатному режимі від каналу CRSF.

3. **Логіка затримки та активації ключа живлення (GPIO 15)**:
   - Пін GPIO 15 керує силовим ключем за допомогою 50Hz PWM сигналу.
   - Ключ активується (**2000us**) через **60 секунд затримки** після того, як опустилися сервоприводи.
   - Головна умова активації ключа: **усі три кінцевики повинні бути одночасно в стані CLOSED (з'єднані з GND / LOW)**.
   - Якщо хоча б один кінцевик відкривається — ключ миттєво вимикається (**1000us**).

4. **Індикація станів за допомогою LED**:
   - На приймачі реалізовано світлову індикацію руху:
     * **Червоний світлодіод (GPIO 21)** світиться, коли сервоприводи перебувають у русі.
     * **Синій світлодіод (GPIO 22)** світиться, коли рух завершено і сервоприводи зупинилися.
   - Світлодіод статусу на **GPIO 27** світиться при спрацюванні верхнього кінцевика.

5. **25% Потужності WiFi**:
   - Для уникнення наведень на радіоканал LoRa, потужність передавача WiFi AP знижена до 25% (~5dBm) на обох платах.
